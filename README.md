# Azooz AI Mini

نموذج ذكاء اصطناعي تجريبي صغير مبني من الصفر باستخدام Kotlin ويعمل محليًا على Android.

## الإصدار 0.1
- شبكة عصبية MLP بسيطة: Bag-of-Words ثم Dense/Tanh ثم Softmax.
- تدريب داخلي على أمثلة عربية مصنفة.
- تصنيف أولي للتحية والعناوين والأزرار والبطاقات والنماذج والألوان والتفاعلات والمساعدة.
- واجهة محادثة Jetpack Compose.
- لا يستخدم Firebase أو Gemini أو API خارجي.

## البناء
- Android Studio وJDK 17.
- Gradle 8.11.1 وAndroid Gradle Plugin 8.9.2.
- Kotlin 2.0.21.
افتح المشروع في Android Studio، نفّذ Gradle Sync، ثم شغّل التطبيق.

## حدود النموذج
هذا الإصدار مصنف نوايا صغير، وليس نموذج لغة توليديًا عامًا. لا يولّد نصوصًا حرة أو HTML كاملًا بعد. بيانات التدريب صغيرة وموجودة داخل ملف NeuralMiniModel.kt، ويجب إضافة مجموعة تحقق واختبار مستقلة قبل اعتبار الدقة موثوقة.

## خارطة الطريق
1. فصل بيانات التدريب والتحقق والاختبار.
2. تحسين تطبيع العربية وتوسيع المفردات.
3. حفظ واسترجاع أوزان النموذج.
4. توليد أوامر HTML/CSS منظمة.
5. دمج المحرك في تطبيق Website Designer.
